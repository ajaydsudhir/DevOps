# Day 11: Install and Configure Tomcat Server

## Task
The `Nautilus` application development team recently finished the beta version of one of their Java-based applications, which they are planning to deploy on one of the app servers in `Stratos DC`. After an internal team meeting, they have decided to use the `tomcat` application server. Based on the requirements mentioned below complete the task:

a. Install `tomcat` server on `App Server 3`.
b. Configure it to run on port `3004`.
c. There is a `ROOT.war` file on `Jump host` at location `/tmp`.

Deploy it on this tomcat server and make sure the webpage works directly on base URL i.e `curl http://stapp03:3004`

## Solution
1. SSH into `App Server 3`:
    ```bash
    ssh banner@stapp03  # Password: BigGr33n
    ```
2. Install Tomcat server:
    ```bash
    sudo yum install -y tomcat tomcat-webapps tomcat-admin-webapps
    ```
3. Enable and start the Tomcat service:
    ```bash
    sudo systemctl enable tomcat
    sudo systemctl start tomcat
    ```
4. Change the Tomcat server port to `3004` by editing the `server.xml` file using the `vi usr/share/tomcat/conf/server.xml` command:
    ```
    <Connector port="3004" protocol="HTTP/1.1" ...    
    ```
5. Restart the Tomcat service to apply the changes:
    ```bash
    sudo systemctl restart tomcat
    ```
6. From `Jump Host`, copy the `ROOT.war` file to `App Server 3`:
    ```bash
    scp /tmp/ROOT.war banner@stapp03:/tmp  # Password: BigGr33n
    ```
7. SSH back to `App Server 3` and move the `ROOT.war` file to the Tomcat webapps directory:
    ```bash
    sudo mv /tmp/ROOT.war /usr/share/tomcat/webapps/
    ```
8. Wait for a few seconds and verify that the application is running by accessing the URL:
    ```bash
    curl http://stapp03:3004
    ```


## Notes
- Tomcat server is a widely used open-source Java Servlet Container that provides a platform for running Java-based web applications. Tomcat implements the Java Servlet, JavaServer Pages (JSP), and WebSocket specifications, making it a popular choice for hosting Java web applications.
- The `ROOT.war` file is a Web Application Archive (WAR) file that contains the compiled Java code, libraries, and resources for the web application. When deployed to Tomcat, it will be accessible at the base URL without any additional context path.
