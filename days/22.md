## Task
The DevOps team established a new Git repository last week, which remains unused at present. However, the Nautilus application development team now requires a copy of this repository on the `Storage Server` in the Stratos DC. Follow the provided details to clone the repository:

## Solution
1. SSH into the `Storage Server` using the provided credentials.
    ```bash
    ssh natasha@ststor01    # Password: Bl@kW
    ```
2. Navigate to the target directory where the repository will be cloned.
    ```bash
    cd /usr/src/kodekloudrepos
    ```
3. Clone the Git repository from the specified location.
    ```bash
    git clone /opt/news.git
    ```
