# Day 13: IPtables Installation And Configuration

## Task
We have one of our websites up and running on our `Nautilus` infrastructure in `Stratos DC`. Our security team has raised a concern that right now Apache’s port i.e `8082` is open for all since there is no firewall installed on these hosts. So we have decided to add some security layer for these hosts and after discussions and recommendations we have come up with the following requirements:

1. Install `iptables` and all its dependencies on each app host.
2. Block incoming port `8082` on all apps for everyone except for LBR host.
3. Make sure the rules remain, even after system reboot.

## Solution
1. SSH into each application server on different terminals and install `iptables`: 
    ```bash
    ssh tony@stapp01    # Password: Ir0nM@n
    sudo dnf install -y iptables iptables-services
    sudo systemctl enable iptables
    sudo systemctl start iptables
    ```
    ```bash
    ssh steve@stapp02   # Password: Am3ric@
    sudo dnf install -y iptables iptables-services
    sudo systemctl enable iptables
    sudo systemctl start iptables
    ```
    ```bash
    ssh banner@stapp03  # Password: BigGr33n
    sudo dnf install -y iptables iptables-services
    sudo systemctl enable iptables
    sudo systemctl start iptables
    ```
2. SSH into the LoadBalancer server and note down its IP address:
    ```bash
    ssh loki@stlb01     # Password: Mischi3f
    ip addr show
    ```
2. Block incoming port `8082` for everyone except for LBR host on each application server:
    ```bash
    sudo iptables -I INPUT -p tcp -s 10.244.195.28 --dport 8082 -j ACCEPT
    sudo iptables -A INPUT -p tcp --dport 8082 -j DROP
    sudo iptables-save | sudo tee /etc/sysconfig/iptables > /dev/null
    ```
3. Verify the rules after rebooting the system:
    ```bash
    sudo systemctl restart iptables
    sudo iptables -L INPUT -n --line-numbers
    ```

## Notes
- `iptables` is a powerful firewall tool that allows you to configure rules for incoming and outgoing traffic on your Linux system. 
- The `-I` option is used to insert a rule at a specific position in the chain, while the `-A` option appends a rule to the end of the chain.
