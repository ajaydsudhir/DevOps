## Solution
1. Login to Jenkins UI using the provided credentials.
2. Navigate to `Manage Jenkins` > `Plugin Manager` and install the `SSH Build Agents` plugin. Restart Jenkins.
3. Navigate to `Manage Jenkins` > `Manage Nodes and Clouds` > `New Node`.
4. Create a new node for `App_server_1`:
    - Node Name: `App_server_1`
    - Node Type: `Permanent Agent`
    - Remote root directory: `/home/tony/jenkins`
    - Labels: `stapp01`
    - Launch method: `Launch agents via SSH`
    - Host: `stapp01`
    - Credentials: Add new credentials for user `tony` with password `Ir0nM@n`
5. Repeat step 4 for `App_server_2` and `App_server_3` with their respective details.
6. After adding all nodes, ensure they are online and connected properly by checking the status in the `Manage Nodes and Clouds` section.
7. If any node is not connecting, ensure java is installed on the app servers and the SSH service is running.

## Notes
- Nodes are used in Jenkins to distribute the workload of building and deploying applications across multiple machines, thus improving efficiency and scalability.
