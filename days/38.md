## Solution
1. SSH into `App Server 3` using the provided credentials.
   ```bash
   ssh banner@stapp03    # Password: BigGr33n
   ```
2. Pull the `busybox:musl` image.
   ```bash
   docker pull busybox:musl
   ```
3. Retag the image as `busybox:news`.
   ```bash
   docker tag busybox:musl busybox:news
   ```
4. Verify that the image has been pulled and retagged successfully.
   ```bash
   docker images
   ```

## Notes
- `docker pull` command is used to download images from Docker Hub.
- `docker tag` command is used to create a new tag for an existing image.
- Tagging an image allows you to reference the same image with different names, which can be useful for versioning or organizing images.
- Docker image is a read-only template used to create containers. It contains the application code, libraries, dependencies, and other necessary files required to run the application.
