## Solution
1. SSH into `App Server 3` using the provided credentials:
   ```bash
   ssh banner@stapp03
   ```
   Password: `BigGr33n`
2. Once logged in, create the user `ammar` with an expiry date:
   ```bash
    sudo useradd -e 2026-12-07 ammar
    ```
3. Verify the user creation and expiry date by checking the `/etc/passwd` file:
   ```bash
    grep ammar /etc/passwd
    ```
    You should see an entry similar to: `ammar:x:1001:1001::/home/ammar:/bin/bash`
4. To check the expiry date and user account information, use the `chage` command:
    ```bash
     sudo chage -l ammar
     ```
