# Day 39: Create a Docker Image From Container

## Task
One of the Nautilus developer was working to test new changes on a container. He wants to keep a backup of his changes to the container. A new request has been raised for the DevOps team to create a new image from this container. Below are more details about it:

## Solution
1. SSH into `App Server 3` using the provided credentials.
   ```bash
   ssh banner@stapp03    # Password: BigGr33n
   ```
2. Check the running containers to find the container ID or name of `ubuntu_latest`.
   ```bash
   docker ps
   ```
3. Create a new image from the running container `ubuntu_latest` and tag it as `beta:devops`.
   ```bash
   docker commit ubuntu_latest beta:devops
   ```
4. Verify that the new image has been created successfully.
   ```bash
   docker images
   ```

## Notes
- `docker commit` command is used to create a new image from a running container.
- The new image will include all the changes made to the container since it was started.
- https://docs.docker.com/reference/cli/docker/container/commit/
