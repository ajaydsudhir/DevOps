# Day 26: Git Manage Remotes

## Task
The xFusionCorp development team added updates to the project that is maintained under `/opt/media.git` repo and cloned under `/usr/src/kodekloudrepos/media`. Recently some changes were made on Git server that is hosted on `Storage server` in `Stratos DC`. The DevOps team added some new Git remotes, so we need to update remote on `/usr/src/kodekloudrepos/media` repository as per details mentioned below:
a. In `/usr/src/kodekloudrepos/media` repo add a new remote `dev_media` and point it to `/opt/xfusioncorp_media.git` repository.
b. There is a file `/tmp/index.html` on same server; copy this file to the repo and add/commit to `master` branch.
c. Finally push `master` branch to this new remote origin.

## Solution
1. SSH into the `Storage Server` using the provided credentials.
   ```bash
   ssh natasha@ststor01    # Password: Bl@kW
   ```
2. Navigate to the `/usr/src/kodekloudrepos/media` directory.
   ```bash
   cd /usr/src/kodekloudrepos/media
   ```
3. Add a new remote named `dev_media` pointing to the `/opt/xfusioncorp_media.git` repository.
   ```bash
   sudo git remote add dev_media /opt/xfusioncorp_media.git
   ```
4. Copy the file `/tmp/index.html` to the repository.
   ```bash
   sudo cp /tmp/index.html .
   ```
5. Add and commit the copied file.
   ```bash
   sudo git add .
   sudo git commit -m "Added index.html"
   ```
6. Push the `master` branch to the new remote `dev_media`.
   ```bash
   sudo git push -u dev_media master
   ```

## Notes
- The `-u` option in the push command sets the upstream for the master branch to the new remote, allowing future pushes to be done with just `git push`.
- `git remote add` command is used to add a new remote repository to the existing local repository.
- https://git-scm.com/docs/git-remote
