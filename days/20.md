# Day 20: Configure Nginx + PHP-FPM Using Unix Sock

## Task
The `Nautilus` application development team is planning to launch a new PHP-based application, which they want to deploy on `Nautilus` infra in `Stratos DC`. The development team had a meeting with the production support team and they have shared some requirements regarding the infrastructure. Below are the requirements they shared:

a. Install `nginx` on `app server 3` , configure it to use port `8099` and its document root should be `/var/www/html`.
b. Install `php-fpm` version `8.1` on `app server 3`, it must use the unix socket `/var/run/php-fpm/default.sock` (create the parent directories if don't exist).
c. Configure `php-fpm` and `nginx` to work together.
d. Once configured correctly, you can test the website using `curl http://stapp03:8099/index.php` command from jump host.

## Solution
1. SSH into `app server 3` and install `nginx` and configure it to use port `8099` and its document root should be `/var/www/html`:
    ```bash
    ssh banner@stapp03    # Password: BigGr33n
    sudo dnf install nginx -y
    sudo vi /etc/nginx/nginx.conf
    ```
    Update the `nginx.conf` file to include the following configuration:
    ```nginx
    server {
        listen       8099;
        listen       [::]:8099;
        server_name  stapp03;
        root         /var/www/html;
        index        index.php index.html;

        # Load configuration files for the default server block.
        include /etc/nginx/default.d/*.conf;

        location / {
            try_files $uri $uri/ =404;
        }

        location ~ \.php$ {
            include fastcgi_params;
            fastcgi_pass unix:/var/run/php-fpm/default.sock;
            fastcgi_index index.php;
            fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        }

        error_page 404 /404.html;
        location = /404.html {
        }

        error_page 500 502 503 504 /50x.html;
        location = /50x.html {
        }
    }
    ```
2. Install `php-fpm` version `8.1` on `app server 3`, it must use the unix socket `/var/run/php-fpm/default.sock`:
    ```bash
    sudo dnf module enable php:8.1 -y
    sudo dnf install php-fpm -y
    sudo vi /etc/php-fpm.d/www.conf
    ```
    Update the `www.conf` file to include the following configuration:
    ```ini
    [www]
    user = nginx
    group = nginx
    listen = /var/run/php-fpm/default.sock
    listen.owner = nginx
    listen.group = nginx
    listen.mode = 0660
    ```
3. Make the parent directories for the unix socket if they don't exist:
    ```bash
    sudo mkdir -p /var/run/php-fpm
    sudo chown nginx:nginx /var/run/php-fpm
    ```
4. Start and enable `php-fpm` and `nginx` services:
    ```bash
    sudo systemctl enable php-fpm nginx
    sudo systemctl start php-fpm nginx
    ```
5. Test the website using `curl http://stapp03:8099/index.php` command from jump host.

## Notes
- `nginx` is a popular web server that can also be used as a reverse proxy, load balancer, and HTTP cache. It is known for its high performance, stability, rich feature set, simple configuration, and low resource consumption.
- `PHP-FPM` (FastCGI Process Manager) is an alternative PHP FastCGI implementation with some additional features useful for heavy-loaded sites. It provides a way to manage PHP processes and can be used to improve the performance of PHP applications.
- Using a unix socket for communication between `nginx` and `php-fpm` can provide better performance compared to using TCP/IP, as it avoids the overhead of network communication.
- Ensure that the permissions for the unix socket are set correctly to allow `nginx` to communicate with `php-fpm`.
