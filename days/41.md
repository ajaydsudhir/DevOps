## Solution
1. SSH into `App Server 3` using the provided credentials.
   ```bash
   ssh banner@stapp03    # Password: BigGr33n
   ```
2. Navigate to the `/opt/docker` directory and create a new file named `Dockerfile`.
   ```bash
   cd /opt/docker
   sudo vi Dockerfile
   ```
3. Add the following content to the `Dockerfile` to meet the requirements:
   ```dockerfile
   FROM ubuntu:24.04

   RUN apt-get update && \
   apt-get install -y apache2 && \
   apt-get clean && \
   rm -rf /var/lib/apt/lists/*

   RUN sed -i 's/Listen 80/Listen 8084/' /etc/apache2/ports.conf && \
   sed -i 's/<VirtualHost \*:80>/<VirtualHost *:8084>/' /etc/apache2/sites-available/000-default.conf

   EXPOSE 8084

   CMD ["/usr/sbin/apache2ctl", "-D", "FOREGROUND"]
   ```
4. Save and exit the file.
5. Build the Docker image using the following command:
   ```bash
   sudo docker build -t custom-apache:latest .
   ```
6. Verify that the image has been created successfully and test the image by running a container from it:
   ```bash
   sudo docker images
   sudo docker run -d -p 8084:8084 custom-apache:latest
   ```

## Notes
- A docker image is a lightweight, standalone, and executable software package that includes everything needed to run a piece of software, including the code, runtime, libraries, and dependencies. Docker images are used to create Docker containers, which are instances of the image that can be run on any system with Docker installed.
- The `Dockerfile` is a text file that contains a set of instructions to build a Docker image. It defines the base image, the software to be installed, configuration settings, and commands to run when the container starts. The `Dockerfile` allows developers to automate the process of creating Docker images, ensuring consistency and reproducibility across different environments.
