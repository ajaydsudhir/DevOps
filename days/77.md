## Solution
1. Login to Jenkins UI using the provided credentials.
2. Navigate to `Manage Jenkins` > `System Configuration` > `Plugins` and install the `GIT`, `GIT Client`, `Pipeline`, `SSH`, `SSH Credentials`, and `SSH Build Agents` plugins. After installation, restart Jenkins.
3. SSH into the Application Server 1 and update `Java` using the following commands:
```bash
sudo yum install java-21-openjdk -y
```
4. On Jenkins UI, navigate to `Credentials` > `System` > `Global` and add a new credential with the following details:
   - Kind: `Username with password`
   - Username: `sarah`
   - Password: `Sarah_pass123`
5. Add a new node in Jenkins with the following details:
   - Node Name: `stapp01`
   - Remote Root Directory: `/home/sarah/jenkins_agent`
   - Labels: `stapp01`
   - Launch method: `Launch agent via SSH`
   - Host: `stapp01`
   - Credentials: Select the credential created in step 4.
6. Create a new pipeline job named `devops-webapp-job` and configure it with the following pipeline script:
```groovy
pipeline {
    agent { label 'stapp01' }
    stages {
        stage('Deploy') {
            steps {
                sh '''
                cd /var/www/html
                git pull origin master
                '''
                }
            }
        }
    }
```
7. Setup passwordless SSH from Jenkins server to the Application Server 1 for the user `sarah` by generating an SSH key pair and adding the public key to the `~/.ssh/authorized_keys` file on the Application Server 1.
8. Trigger the pipeline job and verify that the deployment is successful by checking the application URL
