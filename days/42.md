## Solution
1. SSH into `App Server 1` using the provided credentials.
   ```bash
   ssh tony@stapp01    # Password: Ir0nM@n
   ```
2. Create a docker network named `news` with the specified configurations.
   ```bash
   docker network create --driver=macvlan --subnet=10.10.1.0/24 --ip-range=10.10.1.0/24 news
   ```
3. Verify that the network has been created successfully.
   ```bash
   docker network ls
   ```

## Notes
- A docker network is a virtual network that allows containers to communicate with each other and with the host system. It provides isolation and control over the network traffic between containers.
- The `macvlan` driver allows you to assign a MAC address to a container, making it appear as a physical device on the network. This is useful for scenarios where containers need to be on the same network as the host or other devices.
- `docker network create` command is used to create a new network. The `--driver` option specifies the network driver to use, and the `--subnet` and `--ip-range` options define the IP address range for the network.
- https://docs.docker.com/reference/cli/docker/network/create/
