## Solution
1. SSH into the `Storage Server` using the provided credentials and give sudo privileges.
   ```bash
   ssh natasha@ststor01    # Password: Bl@kW
   sudo su
   ```
2. Navigate to the cloned repository directory.
   ```bash
   cd /usr/src/kodekloudrepos/games
   ```
3. Check the current branches and use the `git log` command to find the commit hash for `Update info.txt` in the `feature` branch.
   ```bash
   git branch
   git log
   ```
4. Switch to the `master` branch and use the `git cherry-pick` command with the commit hash obtained from the previous step to merge the specific commit into `master`.
   ```bash
   git switch master
   git cherry-pick 73da38a1c4a9a88f29e77953f5d043431411aeee
   ```
5. Push the changes to the remote repository.
   ```bash
   git push origin master
   ```

## Notes
- `git cherry-pick` is a command that allows you to apply the changes introduced by an existing commit from one branch onto another branch. It is useful when you want to merge specific changes without merging the entire branch.
- https://git-scm.com/docs/git-cherry-pick
