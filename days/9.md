## Notes
- The issue was caused by incorrect permissions on the `/run/mariadb` directory, which prevented the mariadb service from starting. By changing the ownership of the directory to `mysql:mysql`, we were able to resolve the issue and start the mariadb service successfully.
- To solve it, we need to create the right directory, assigning correct permissions, and initializing system tables.
