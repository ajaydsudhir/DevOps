# Day 72: Jenkins Parameterized Builds

## Task
A new DevOps Engineer has joined the team and he will be assigned some Jenkins related tasks. Before that, the team wanted to test a simple parameterized job to understand basic functionality of parameterized builds. He is given a simple parameterized job to build in Jenkins. Please find more details below:

Click on the `Jenkins` button on the top bar to access the Jenkins UI. Login using username `admin` and password `Adm!n321`.

1. Create a `parameterized` job which should be named as `parameterized-job`

2. Add a `string` parameter named `Stage`; its default value should be `Build`.

3. Add a `choice` parameter named `env`; its choices should be `Development`, `Staging` and `Production`.

4. Configure job to execute a shell command, which should echo both parameter values (you are passing in the job).

5. Build the Jenkins job at least once with choice parameter value `Production` to make sure it passes.

## Solution
1. Login to Jenkins UI using the credentials provided above.
2. Create a new Jenkins job named `parameterized-job`. Go to the Jenkins dashboard, click on `New Item`, enter the name `parameterized-job`, select `Freestyle project`, and click `OK`.
3. Configure the job to be parameterized. In the job configuration, check the `This project is parameterized` option, click `Add Parameter`, select `String Parameter`, and set the name to `Stage` and default value to `Build`.
4. Add a choice parameter named `env`. Click `Add Parameter`, select `Choice Parameter`, set the name to `env`, and enter the choices as `Development`, `Staging`, and `Production`.
5. Add a build step to execute a shell command that echoes both parameter values. In the job configuration, under `Build`, click `Add build step`, select `Execute shell`, and enter the following command:
```bash
echo "Stage: $Stage"
echo "Environment: $env"
```
6. Save the job configuration and build the job at least once with the choice parameter value set to `Production`. Click `Build with Parameters`, select `Production` from the `env` dropdown, and click `Build`.
7. Verify that the job runs successfully and echoes the correct parameter values.
