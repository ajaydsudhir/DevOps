# Day 1: Linux User Setup with Non-Interactive Shell

## Task

## Solution
1. SSH into `App Server 2` using the provided credentials:
   ```bash
   ssh steve@stapp02
   ```
   Password: `Am3ric@`
2. Once logged in, create the user `ammar` with a non-interactive shell:
   ```bash
   sudo useradd -s /sbin/nologin ammar
   ```
3. Verify the user creation by checking the `/etc/passwd` file:
   ```bash
   grep ammar /etc/passwd
   ```
   You should see an entry similar to: `ammar:x:1001:1001::/home/ammar:/sbin/nologin`
