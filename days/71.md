## Solution
1. Access the Jenkins UI by clicking on the `Jenkins` button in the top bar. Log in using the credentials: username `admin` and password `Adm!n321`.
2. Install the `Publish Over SSH` plugin if it is not already installed. Go to `Manage Jenkins` > `Manage Plugins` > `Available` tab, search for `Publish Over SSH`, select it, and click `Restart Jenkins when installation is complete and no jobs are running`.
3. Add the SSH server configuration for the `storage server`. Go to `Manage Jenkins` > `Configure System` > `Publish over SSH` section, and add a new SSH server with the following details:
   - Name: `Storage Server`
   - Hostname: `ststor01`
   - Username: `natasha`
   - Password (Under advanced): `Bl@kW`
4. Create a new Jenkins job named `install-packages`. Go to the Jenkins dashboard, click on `New Item`, enter the name `install-packages`, select `Freestyle project`, and click `OK`.
5. Configure the job with a string parameter named `PACKAGE`. In the job configuration, check the `This project is parameterized` option, click `Add Parameter`, select `String Parameter`, and set the name to `PACKAGE`.
6. Add a build step to execute a shell command that installs the package specified in the `$PACKAGE` parameter on the `storage server`. In the job configuration, under `Build`, click `Add build step`, select `Send files or execute commands over SSH`, choose the `Storage Server` from the dropdown, and enter the following command:
```bash
#!/bin/bash
PACKAGE_PASSWORD="Bl@kW"
echo "Installing package: $PACKAGE"
echo $PACKAGE_PASSWORD | sudo -S yum install -y $PACKAGE
if [ $? -eq 0 ]; then
    echo "Package $PACKAGE installed successfully."
else
    echo "Failed to install package $PACKAGE."
    exit 1
fi
```
7. Save the job configuration and build the job at least once with a parameter (e.g., `PACKAGE=vim-enhanced`) to ensure the package is installed on the Storage server. Click `Build with Parameters`, enter `vim-enhanced` in the `PACKAGE` field, and click `Build`.
8. Verify that the package has been installed successfully on the Storage server by SSHing into the server and checking the package installation:
```bash
ssh natasha@ststor01
rpm -q vim-enhanced
```
