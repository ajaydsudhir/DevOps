# Day 47: Docker Python App

## Task
A python app needed to be Dockerized, and then it needs to be deployed on `App Server 2`. We have already copied a `requirements.txt` file (having the app dependencies) under `/python_app/src/` directory on `App Server 2`. Further complete this task as per details mentioned below:
1. Create a `Dockerfile` under `/python_app` directory:
   - Use any `python` image as the base image.
   - Install the dependencies using `requirements.txt` file.
   - Expose the port `8082`.
   - Run the `server.py` script using `CMD`.
2. Build an image named `nautilus/python-app` using this Dockerfile.
3. Once image is built, create a container named `pythonapp_nautilus`:
   - Map port `8082` of the container to the host port `8099`.
4. Once deployed, you can test the app using `curl` command on `App Server 2`.
> curl http://localhost:8099/

## Solution
1. SSH into `Application Server 2` using the provided credentials.
   ```bash
   ssh steve@stapp02    # Password: Am3ric@
   ```
2. Navigate to the `/python_app` directory and create a `Dockerfile` with the following content:
   ```dockerfile
   FROM python:3.9-slim
   WORKDIR /app
   COPY ./src/* /app/
   RUN pip install -r requirements.txt
   EXPOSE 8082
   CMD ["python", "server.py"]
   ```
3. Build the Docker image named `nautilus/python-app`:
   ```bash
   docker build -t nautilus/python-app .
   ```
4. Run a container named `pythonapp_nautilus` and map port `8082` of the container to host port `8099`:
   ```bash
   docker run -d --name pythonapp_nautilus -p 8099:8082 nautilus/python-app
   ```
5. Test the application using `curl`:
   ```bash
   curl http://localhost:8099/
   ```

## Notes
- The `Dockerfile` uses a slim version of Python 3.9 as the base image, which is lightweight and suitable for running Python applications.
- The `requirements.txt` file should be present in the `/python_app/src/` directory and contain all necessary dependencies for the Python application.
