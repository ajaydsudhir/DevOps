## Solution
1. Login to Jenkins UI using the provided credentials.
2. Navigate to `Manage Jenkins` > `System Configuration` > `Plugins` and install the `GIT`, `Credentials`, `Pipeline`, `Pipeline: Job`, `Workflow`, `SSH Agent`, and `SSH Build Agents` plugins. After installation, restart Jenkins.
3. Create a new node in Jenkins with the following details:
   - Node Name: `App Server 1`
   - Remote Root Directory: `/home/sarah/jenkins_agent`
   - Labels: `stapp01`
   - Launch method: `Launch agent via SSH`
   - Host: `stapp01`
   - Credentials: Create for tony user with password `Ir0nM@n` and id as `stapp01`.
   - Credentials: Create for sarah user with password `Sarah_pass123` and id as `sarah`.
   - Host Key Verification Strategy: `Non verifying Verification Strategy`
4. SSH into `App Server 1` and install `Java` using the following commands:
```bash
ssh tony@stapp01
sudo yum install java-17-openjdk-devel -y
```
5. Switch user to `sarah` and install `Java` using the following commands:
```bash
su - sarah
sudo yum install java-17-openjdk-devel -y
```
6. Create a pipeline job named `xfusion-webapp-job` in Jenkins with the following configuration:
   - Add a string parameter named `BRANCH` with default value `master` and description `Branch to deploy (master or feature)`.
   - Use the following pipeline script:
```groovy
pipeline {
    agent { label 'stapp01' }
    parameters {
        string(name: 'BRANCH', defaultValue: 'master', description: 'Branch to deploy')
    }
    stages {
        stage('Deploy') {
            steps {
                script {
                    if (params.BRANCH == 'master') {
                        sh '''
                            cd /var/www/html
                            git fetch origin
                            git checkout master
                            git pull origin master
                        '''
                    } else if (params.BRANCH == 'feature') {
                        sh '''
                            cd /var/www/html
                            git fetch origin
                            git checkout feature
                            git pull origin feature
                        '''
                    } else {
                        error("Invalid branch specified. Please use 'master' or 'feature'.")
                    }
                }
            }
        }
    }
}
```
7. Run builds for both `master` and `feature` branches by providing the respective values in the `BRANCH` parameter and verify that the deployment is successful by checking the application URL.
