## Solution
1. Login to Jenkins UI using the provided credentials.
2. Navigate to `Manage Jenkins` > `System Configuration` > `Plugins` and install the `GIT`, `Credentials`, `Pipeline` and `SSH Build Agents` plugins.
3. SSH into App Server 1 and switch to user `sarah`.
4. Update the `index.html` file in the `/var/www/html` directory with the content `Welcome to xFusionCorp Industries` and install `java-17-openjdk` using the command `sudo yum install -y java-17-openjdk`.
5. In Jenkins, nagigate to `Manage Jenkins` > `Credentials` and add a new credential for user `sarah` with the provided password.
6. Navigate to `Manage Jenkins` > `Nodes` and create a new node named `App Server 1` with label `stapp01`, remote root directory `/home/sarah/jenkins_agent`, and launch method as `Launch agent via SSH` using the credentials created in the previous step.
7. Create a new pipeline job named `deploy-job` and configure the pipeline script as follows:
```groovy
pipeline {
    agent { label 'stapp01' }

    stages {
        stage('Deploy') {
            steps {
                sh """
                    cd /var/www/html
                    git fetch origin
                    git reset --hard origin/master
                """
            }
        }
        
        stage('Test') {
            steps {
                sh """
                    curl -f http://stlb01:8091
                """
            }
        }
    }
}
```
8. Ensure the changes made to the `index.html` file are still present and then push the changes to the `master` branch using the following commands:
```bash
cd /var/www/html
git add index.html
git commit -m "Update index.html content"
git push origin master
```

## Notes
- Stages in a Jenkins pipeline are used to define different steps in the CI/CD process. 
- The `Build` stage is responsible for building the code, the `Deploy` stage is responsible for deploying the code to the application server, while the `Test` stage checks if the deployment was successful by making a request to the application URL.
