## Solution
1. Open the Jenkins UI and log in with the provided credentials.
2. Click on `New Item` to create a new job.
3. Enter the job name as `database-backup` and select `Freestyle project`, then click `OK`.
4. In the job configuration page, scroll down to the `Build` section and click on `Add build step`, then select `Execute shell`.
5. In the shell command box, enter the following command to take a database dump and copy it to the storage server:
```bash
BACKUP_DIR="/home/natasha/db_backups"
BACKUP_FILE="db_$(date +%F).sql"

ssh tony@stapp01 "mysqldump -u kodekloud_roy -pasdfgdsd kodekloud_db01" | ssh natasha@ststor01 "cat > $BACKUP_DIR/$BACKUP_FILE"

ssh natasha@ststor01 "ls -lh $BACKUP_DIR/$BACKUP_FILE"
```
6. Scroll down to the `Build Triggers` section and check the `Build periodically` option. Enter the schedule `*/10 * * * *` in the text box.
7. Click `Save` to save the job configuration.
8. SSH into the Jenkins server and create a SSH key pair for the `jenkins` user if it doesn't already exist:
```bash
ssh jenkins@jenkins 
ssh-keygen -t rsa -b 2048 -N "" 
cat ~/.ssh/id_rsa.pub
```
9. Copy the public key and add it to the `~/.ssh/authorized_keys` file of both `tony` on `stapp01` and `natasha` on `ststor01` to allow passwordless SSH access using `ssh-copy-id <user>@<host>`.

## Notes
- Database backups are critical for disaster recovery and data integrity. 
- Dumping the database and storing it in a secure location ensures that you can restore the database in case of data loss or corruption.
