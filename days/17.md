## Solution
1. SSH into `stdb01`:
    ```bash
    ssh peter@stdb01    # Password: Sp!dy
    ```
2. Create a database user `kodekloud_roy` and set its password to `BruCStnMT5`:
    ```bash
    sudo -i -u postgres
    psql -c "CREATE USER kodekloud_roy WITH PASSWORD 'BruCStnMT5';"
    ```
3. Create a database `kodekloud_db10`:
    ```bash
    psql -c "CREATE DATABASE kodekloud_db10;"
    ```
4. Grant full permissions to user `kodekloud_roy` on the database `kodekloud_db10`:
    ```bash
    psql -c "GRANT ALL PRIVILEGES ON DATABASE kodekloud_db10 TO kodekloud_roy;"
    ```
5. Verify the user and database creation:
    ```bash
    psql -c "\du"          # List all users
    psql -c "\l"           # List all databases
    ```
6. Exit the PostgreSQL prompt:
    ```bash
    \q
    ```
