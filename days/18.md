## Solution
1. SSH into `stdb01`:
    ```bash
    ssh peter@stdb01    # Password: Sp!dy
    ```
2. Install MariaDB server:
    ```bash
    sudo dnf install mariadb-server -y
    ```
3. Start and enable MariaDB service:
    ```bash
    sudo systemctl start mariadb
    sudo systemctl enable mariadb
    sudo systemctl status mariadb
    ```
4. Secure MariaDB installation:
    ```bash
    sudo mysql_secure_installation
    ```
5. Log in to MariaDB shell:
    ```bash
    mysql -u root -p
    ```
6. Create database `kodekloud_db6`:
    ```sql
    CREATE DATABASE kodekloud_db6;
    ```
7. Create user `kodekloud_gem` with password `dCV3szSGNA`:
    ```sql
    CREATE USER 'kodekloud_gem'@'%' IDENTIFIED BY 'dCV3szSGNA';
    ```
8. Grant full permissions to user `kodekloud_gem` on database `kodekloud_db6`:
    ```sql
    GRANT ALL PRIVILEGES ON kodekloud_db6.* TO 'kodekloud_gem'@'%';
    FLUSH PRIVILEGES;
    ```

## Notes
-  `MariaBD` is a popular open-source relational database management system that is a fork of MySQL. It is widely used for web applications and other database-driven applications.
- The `mysql_secure_installation` command is used to improve the security of the MariaDB installation by setting a root password, removing anonymous users, disallowing remote root login, and removing test databases.
- The `GRANT ALL PRIVILEGES` command gives the specified user full access to the specified database, allowing them to perform any action on that database. The `FLUSH PRIVILEGES` command is used to reload the privileges from the grant tables in the MariaDB server, ensuring that the changes take effect immediately.
