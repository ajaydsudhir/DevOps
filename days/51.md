## Task
An application currently running on the Kubernetes cluster employs the nginx web server. The Nautilus application development team has introduced some recent changes that need deployment. They've crafted an image `nginx:1.19` with the latest updates.

Execute a rolling update for this application, integrating the `nginx:1.19` image. The deployment is named `nginx-deployment`.

Ensure all pods are operational post-update.

## Solution
1. Verify the current deployment and its pods:
   ```bash
   kubectl get deployments
   kubectl get pods
   ```
2. Export the current deployment configuration to a YAML file:
   ```bash
   kubectl get deployment nginx-deployment -o yaml > /tmp/nginx-deployment.yaml
   ```
3. Use command `sudo vi /tmp/nginx-deployment.yaml` to edit the YAML file and update the image version from `nginx:1.16` to `nginx:1.19`.
4. Check the differences between the current deployment and the updated configuration:
   ```bash
   kubectl diff -f /tmp/nginx-deployment.yaml
   ```
5. Apply the updated deployment configuration:
   ```bash
   kubectl apply -f /tmp/nginx-deployment.yaml
   ```
6. Monitor the rollout status to ensure the update is successful:
   ```bash
   kubectl rollout status deployment/nginx-deployment
   ```
7. Verify that all pods are running the updated image:
   ```bash
   kubectl describe pods
   ```

## Notes
- Rolling updates in Kubernetes allow for zero-downtime deployments by gradually replacing old pods with new ones.
- The `kubectl diff` command is useful for previewing changes before applying them.
- The `kubectl describe` command provides detailed information about the current state of the pods.
- The `kubectl rollout status` command helps track the progress of the deployment update, ensuring that all pods are updated successfully.
- The `kubectl apply` command is used to apply the changes made in the YAML configuration file to the existing deployment.
- The `kubectl get deployments` and `kubectl get pods` commands are essential for verifying the current state of the deployment and its associated pods before and after the update.
