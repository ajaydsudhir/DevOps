## Notes
- `Fork` is a feature in Git that allows you to create a personal copy of someone else's repository. This is useful for contributing to projects or working on your own version of a project without affecting the original repository.
- After forking the repository, you can clone it to your local machine, make changes, and then push those changes back to your forked repository. If you want to contribute back to the original repository, you can create a pull request from your forked repository to the original repository.
- https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo
