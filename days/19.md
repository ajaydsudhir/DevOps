a. Install `httpd` package and dependencies on `app server 3`.
b. Apache should serve on port `8086`.
c. There are two website's backups `/home/thor/ecommerce` and `/home/thor/demo` on `jump_host`. Set them up on Apache in a way that `ecommerce` should work on the link `http://localhost:8086/ecommerce/` and `demo` should work on link `http://localhost:8086/demo/` on the mentioned app server.
d. Once configured you should be able to access the website using `curl` command on the respective app server, i.e `curl http://localhost:8086/ecommerce/` and `curl http://localhost:8086/demo/`

## Solution
1. SSH into `app server 3` and install `httpd` package:
    ```bash
    ssh banner@stapp03  # Password: BigGr33n
    sudo dnf install httpd -y
    ```
2. Configure Apache to serve on port `8086`:
    - Edit the Apache configuration file:
    ```bash
    sudo vi /etc/httpd/conf/httpd.conf
    ```
    - Change the `Listen` directive to `8086`:
    ```
    Listen 8086
    ```
3. Set up the website already on `jump_host`:
    ```bash
    scp -r /home/thor/ecommerce banner@stapp03:/home/banner/
    scp -r /home/thor/demo banner@stapp03:/home/banner/
    ```
4. Set permissions for the website directories:
    ```bash
    sudo chmod -R 755 /home/banner/ecommerce
    sudo chmod -R 755 /home/banner/demo
    ```
5. Create Apache configuration for the websites:
    - Create a new configuration file for the websites:
    ```bash
    sudo vi /etc/httpd/conf.d/websites.conf
    ```
    - Add the following content to the file:
    ```
    <VirtualHost *:8086>
        DocumentRoot "/home/banner/ecommerce"
        ServerName localhost

        <Directory "/home/banner/ecommerce">
            AllowOverride All
            Require all granted
        </Directory>
    </VirtualHost>

    <VirtualHost *:8086>
        DocumentRoot "/home/banner/demo"
        ServerName localhost

        <Directory "/home/banner/demo">
            AllowOverride All
            Require all granted
        </Directory>
    </VirtualHost>
    ```
6. Restart Apache and enable:
    ```bash
    sudo systemctl restart httpd
    sudo systemctl enable httpd
    ```
7. If you try to access the websites using `curl` command, you will get a `403 Forbidden` error.
    ```Output
    [banner@stapp03 ~]$ curl http://localhost:8086/ecommerce/
    <!DOCTYPE HTML PUBLIC "-//IETF//DTD HTML 2.0//EN">
    <html><head>
    <title>403 Forbidden</title>
    </head><body>
    <h1>Forbidden</h1>
    <p>You don't have permission to access this resource.</p>
    </body></html>
    ```
8. Give permission to the Apache user to access the website directories:
    ```bash
    chmod o+x /home/banner
    chmod -R 755 /home/banner/ecommerce
    chmod -R 755 /home/banner/demo
    ```
9. Ensure that the directories exist:
    ```bash
    sudo mkdir -p /var/www/html/ecommerce
    sudo mkdir -p /var/www/html/demo
    ```
10. Copy the website files to the Apache document root:
    ```bash
    sudo cp -r /home/banner/ecommerce/* /var/www/html/ecommerce/
    sudo cp -r /home/banner/demo/* /var/www/html/demo/
    ```
11. Remove the old website configuration file and restart Apache:
    ```bash
    sudo rm -f /etc/httpd/conf.d/websites.conf
    sudo systemctl restart httpd
    ```
12. Test the websites:
    ```bash
    curl http://localhost:8086/ecommerce/
    curl http://localhost:8086/demo/
    ```

## Notes
- The `403 Forbidden` error occurs because the Apache user does not have permission to access the website directories. To fix this, we need to change the ownership of the website directories to the Apache user and give them the necessary permissions.
- It's important to ensure that the Apache configuration is correct and that the document root is set to the correct directory where the website files are located.
