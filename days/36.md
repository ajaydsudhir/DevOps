## Solution
1. SSH into Application Server 2 using the provided credentials.
   ```bash
   ssh steve@stapp02    # Password: Am3ric@
   ```
2. Pull the nginx image with the alpine tag.
   ```bash
   docker pull nginx:alpine
   ```
3. Create and run the nginx container named `nginx_2`.
   ```bash
   docker run -d --name nginx_2 nginx:alpine
   ```
4. Verify that the container is running.
   ```bash
   docker ps
   ```

## Notes
- The nginx container is used for serving web content and is lightweight when using the alpine tag.
- `Alpine` tag is a minimal Docker image based on Alpine Linux, which is known for its small size and security features.
