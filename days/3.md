# Day 3: Secure Root SSH Access

## Task
Following security audits, the `xFusionCorp Industries` security team has rolled out new protocols, including the restriction of direct root SSH login.
Your task is to disable direct SSH root login on all app servers within the `Stratos Datacenter`.

| Application Server 2 | Dynamic | stapp02   | steve   | Am3ric@    | Hosts Nautilus Application 2                |

## Solution
1. Connect to each application server using the provided credentials on three separate terminals.
   ```bash
   ssh tony@stapp01       # Terminal 1 - Password: Ir0nM@n
   ssh steve@stapp02      # Terminal 2 - Password: Am3ric@
   ssh banner@stapp03     # Terminal 3 - Password: BigGr33n
   ```
2. Open the SSH daemon configuration file to disable root login.
   ```bash
   sudo vi /etc/ssh/sshd_config
   ```
3. Press `i` to enter insert mode, then find the line containing `PermitRootLogin` by searching for it (`/PermitRootLogin`) and change its value to `no`.
   ```bash
   PermitRootLogin no
   ```
4. Save the changes and exit the editor by pressing `Esc`, typing `:wq`, and hitting `Enter`.
5. Restart the SSH service to apply the changes.
   ```bash
   sudo systemctl restart sshd
   ```
6. Verify that root login is disabled by attempting to SSH into the server as root.
   ```bash
   ssh root@stapp01
   ```
7. Check the SSH daemon configuration to confirm that the setting has been applied.
   ```bash
   sudo sshd -T | grep permitrootlogin
   ```
   The output should show `permitrootlogin no`, confirming that root login has been successfully disabled.
