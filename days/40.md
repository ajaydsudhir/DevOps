## Solution
1. SSH into `App Server 1` using the provided credentials.
   ```bash
   ssh tony@stapp01    # Password: Ir0nM@n
   ```
2. List all running containers to identify the `kkloud` container.
   ```bash
   docker ps
   ```
3. Execute a bash shell inside the `kkloud` container.
   ```bash
   docker exec -it kkloud bash
   ```
4. Update the package list and install `apache2`.
   ```bash
   apt update
   apt install apache2 -y
   ```
5. Modify the Apache configuration to listen on port `5003`.
   ```bash
   sed -i 's/Listen 80/Listen 5003/' /etc/apache2/ports.conf
   sed -i 's/<VirtualHost \*:80>/<VirtualHost *:5003>/' /etc/apache2/sites-available/000-default.conf
   ```
6. Start the Apache service inside the container.
   ```bash
   service apache2 start
   ```
7. Verify that Apache is running.
   ```bash
   service apache2 status
   ```

## Notes
- The Apache service is used for serving web content and is a crucial part of many web applications.
- Using a docker container for the Apache service allows for isolated and consistent environments, making it easier to manage dependencies and configurations.
