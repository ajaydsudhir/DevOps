## Solution
1. Create a deployment named `httpd`:
   ```bash
   kubectl create deployment httpd --image=httpd:latest
   ```
2. Verify the deployment creation:
   ```bash
   kubectl get deployments
   ```

## Notes
- `httpd` is a popular open-source web server software. In this task, we created a deployment named `httpd` using the `httpd:latest` image.
- `kubectl` is the command-line tool for interacting with Kubernetes clusters. 
- The `kubectl create deployment` command is used to create the deployment, specifying the image to be used.
