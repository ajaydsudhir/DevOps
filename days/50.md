# Day 50: Set Resource Limits in Kubernetes Pods

## Task
The Nautilus DevOps team has noticed performance issues in some Kubernetes-hosted applications due to resource constraints. To address this, they plan to set limits on resource utilization. Here are the details:

Create a pod named `httpd-pod` with a container named `httpd-container`. Use the `httpd` image with the `latest` tag (specify as `httpd:latest`). Configure the following container-level resource requests and limits for the container:

**Requests:** Memory: `15Mi`, CPU: `100m`
**Limits:** Memory: `20Mi`, CPU: `100m`

## Solution
1. Create a YAML file named `httpd-pod.yaml` (Command: `vi httpd-pod.yaml`) with the following content:
   ```yaml
   apiVersion: v1
   kind: Pod
   metadata:
      name: httpd-pod
   spec:
      containers:
         - name: httpd-container
         image: httpd:latest
         resources:
            requests:
               memory: "15Mi"
               cpu: "100m"
            limits:
               memory: "20Mi"
               cpu: "100m"
   ```
2. Apply the YAML file to create the pod:
   ```bash
   kubectl apply -f httpd-pod.yaml
   ```
3. Verify the pod creation and resource limits:
   ```bash
   kubectl get pods
   kubectl describe pod httpd-pod
   ```

## Notes
- The `requests` field specifies the minimum amount of resources that the container is guaranteed to have.
- The `limits` field specifies the maximum amount of resources that the container can use. 
- Setting these values helps ensure that the application runs efficiently without overloading the cluster.
