## Solution
1. Create `playbook.yml`:
```yaml
- name: Install and configure vsftpd
  hosts: all
  become: true
  tasks:
    - name: Install vsftpd package
      yum:
        name: vsftpd
        state: present
  
    - name: Start and enable vsftpd service
      service:
        name: vsftpd
        state: started
        enabled: yes
```
2. Run the playbook from the jump host:
```bash
ansible-playbook -i inventory playbook.yml
```
3. Verify the installation and service status on all app servers:
```bash
ansible all -i inventory -a "systemctl status vsftpd"
```
