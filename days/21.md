## Task

## Solution
1. SSH into the `Storage Server` using the provided credentials.
    ```bash
    ssh natasha@ststor01    # Password: Bl@kW
    ```
2. Using `yum`, install the `git` package:
    ```bash
    sudo yum install git -y
    ```
3. Create a bare Git repository named `/opt/blog.git`:
    ```bash
    sudo mkdir -p /opt/blog.git
    sudo git init --bare /opt/blog.git
    ```

## Notes
- `Yum` is the package manager for RHEL-based distributions, and the `-y` flag automatically confirms the installation.
- `Git` is a distributed version control system widely used for source code management in software development.
- A bare repository is a repository that does not have a working directory and is typically used as a central repository for collaboration.
