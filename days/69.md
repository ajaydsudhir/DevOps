# Day 69: Install Jenkins Plugins

## Task
The Nautilus DevOps team has recently setup a Jenkins server, which they want to use for some CI/CD jobs. Before that they want to install some plugins which will be used in most of the jobs. Please find below more details about the task

1. Click on the Jenkins button on the top bar to access the Jenkins UI. Login using username `admin` and password `Adm!n321`.

2. Once logged in, install the `Git` and `GitLab` plugins. You may need to restart Jenkins to complete the plugin installation; if required, opt to **Restart Jenkins when installation is complete and no jobs are running** on the plugin installation/update page (Update Centre).

**Note:**
1. After restarting Jenkins, wait for the login page to reappear before proceeding.
2. For tasks involving web UI changes, capture screenshots to share for review or consider using screen recording software like loom.com for documentation and sharing.

## Solution
1. Log in to the Jenkins server using the provided credentials.
2. Navigate to **Manage Jenkins** > **Manage Plugins**.
3. In the **Available** tab, search for `Git` and select it for installation.
4. Similarly, search for `GitLab` and select it for installation.
5. Click on **Install without restart** or **Download now and install after restart** based on your preference. If you choose to install without restart, Jenkins will install the plugins immediately. If you choose to install after restart, Jenkins will queue the installation and complete it after a restart.
6. If you opted for a restart, wait for Jenkins to restart and log back in using the same credentials.
7. Verify that both `Git` and `GitLab` plugins are installed by navigating to **Manage Jenkins** > **Manage Plugins** > **Installed** tab and checking for the presence of the plugins in the list.

## Notes
- Plugins are essential for extending Jenkins functionality, and the `Git` and `GitLab` plugins are commonly used for integrating version control systems with Jenkins.
- https://www.jenkins.io/doc/book/managing/plugins/
