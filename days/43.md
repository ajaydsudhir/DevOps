# Day 43: Docker Ports Mapping

## Task
The Nautilus DevOps team is planning to host an application on a nginx-based container. There are number of tickets already been created for similar tasks. One of the tickets has been assigned to set up a nginx container on `Application Server 1` in `Stratos Datacenter`. Please perform the task as per details mentioned below:
1. Pull `nginx:alpine-perl` docker image on `Application Server 1`.
2. Create a container named `ecommerce` using the image you pulled.
3. Map host port `8087` to container port `80`. Please keep the container in running state.

## Solution
1. SSH into `Application Server 1` using the provided credentials.
   ```bash
   ssh tony@stapp01    # Password: Ir0nM@n
   ```
2. Pull the `nginx:alpine-perl` docker image.
   ```bash
   docker image pull nginx:alpine-perl
   ```
3. Create and run a container named `ecommerce`, mapping host port `8087` to container port `80`.
   ```bash
   docker container run -d --name ecommerce -p 8087:80 nginx:alpine-perl
   ```
4. Verify that the container is running and the port mapping is correct.
   ```bash
   docker ps
   ```

## Notes
- `nginx:alpine-perl` is a lightweight version of the nginx image that includes Perl support, which can be useful for certain web applications.
- `docker image pull` command is used to download the specified image from Docker Hub.
- `docker container run` command is used to create and start a new container from the specified image, with the `-d` flag to run it in detached mode, and `-p` to map ports.
- `docker ps` command is used to list the running containers.
